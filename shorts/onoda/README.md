## 내레이션 원고 (TTS에 그대로 붙여넣기)
```
종전 이십구 년 뒤에 항복한 군인.
필리핀 루방섬의 정글.
일본군 소위 오노다 히로.
받은 명령은 단 하나.
항복도 자결도 하지 마라.
일본은 이미 항복했지만,
정글에 종전 전단이 뿌려졌다.
그는 적의 속임수라 믿었다.
동료들은 하나둘 죽거나 떠났고,
섬 주민 약 삼십 명이 희생됐다.
그런데 그를 찾아낸 건 군대가 아니었다.
스물네 살 여행자, 스즈키 노리오.
상관 명령 없인 못 나간다.
스즈키는 옛 상관을 찾아냈다.
서점 주인이 된 다니구치 전 소령.
그가 정글로 와 임무를 해제했다.
그제야 오노다는 칼을 내려놓았다.
단 한 줄의 명령을 기다리다,
```
